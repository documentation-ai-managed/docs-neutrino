## Quick Start

Creating your first documentation space in Neutrino is simple:

1. Log in to your Neutrino dashboard.
2. Click **“New Documentation Space”**.
3. Set a name and description for your project.
4. Choose a visibility option (private or public).
5. Click **“Create”** to launch your space.

You can now start adding documentation pages, organizing content, and inviting collaborators. All management is in one place.
